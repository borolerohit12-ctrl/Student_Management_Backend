FSJP ASSIGNMENT-2 - QUICK START

1. Install Java 17+, Maven, MySQL Server, and Postman.
2. Open MySQL Workbench and run database.sql.
3. Edit src/main/resources/application.properties and set your MySQL username/password.
4. Open a terminal in this folder and run: mvn spring-boot:run
5. Import postman/Student_Management_API.postman_collection.json into Postman.
6. Run Register User, then Login User, then the student requests in order.
7. Capture real Postman screenshots for the report.
8. Upload this project to your own GitHub repository and add that link to the report.
